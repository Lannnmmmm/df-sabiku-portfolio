# Dewi Fatmawaty Sabiku — Academic Portfolio

Bilingual academic portfolio concept for profile, research, publications, and professional contributions.

## Stack
- React + TypeScript + Vite
- Three.js via React Three Fiber
- Responsive editorial design and interactive 3D seed scene
- GitHub Pages deployment through GitHub Actions

## Local development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Deployment
The GitHub Actions workflow builds the project and deploys `dist/` to GitHub Pages when changes are pushed to `main`.

Target URL: https://lannnmmmm.github.io/df-sabiku-portfolio/

## Content integrity
Initial content links to publicly available academic records. Verify author metadata and publication details before presenting them as confirmed facts. Decorative visuals are not represented as actual research documentation.
